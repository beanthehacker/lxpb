LXPB spike-only-beyond-ATR -- Jul-Aug 2026 retests

spike-only-beyond-ATR. Each row is a completed LXPB retest whose formation bar is a spike (patterns-pure find_shooting_star for LHPB / find_hammer for LLPB). Entry is the level itself on the Phase 2 retest; the stop is beyond the breakout candle (its low for LHPB, its high for LLPB) and the target is the FTA (first trouble area — the running extreme carved out between breakout and retest). A level is only traded when price is beyond the moving daily-ATR boundary — either already at entry, or by the time it would reach the stop: ATR(21) over D1 candles built by calculateD1W1 that closed before the trade's own session, subtracted from the high of the trading day so far (LHPB) or added to the low so far (LLPB), measured strictly point-in-time — only bars already closed plus the retest bar's open and the level price, never the retest bar's own high/low. Either way the market has to exceed a full ATR of daily range, measured from the extreme it has already printed, before the trade can be stopped out. (For a normally-oriented bracket the stop leg subsumes the entry leg, so the Beyond ATR? pill usually reads BEYOND @stop; both margins are shown so you can see which leg carried it.)

Phase 0 = formation (spike), Phase 1 = breakout, Phase 2 = retest/entry, plus a 4th marker at the resolved exit — all on the expandable H1 chart, which spans 8 bars before Phase 0 through the exit bar (+3). Gold line = this row's level/entry, green dashed = FTA target, red dashed = structural stop, orange dotted = the ATR boundary, grey dotted = the day extreme it is measured from, and blue/red dashed = other same-type LXPB levels within 20 ticks (5.00 pts) already broken out by the retest time. Outcomes come from a 1-minute walk-forward with the exact fill pinned on 1s real ticks (look-ahead free: nothing before the fill instant can resolve the trade). All times are PT. The Cluster column/blue banding flags rows sharing the same retest H1 bar — 0 of 1 rows here, collapsing to 1 unique retest bars. Feature checkboxes and the "Valid" verdict are pre-checked from computed defaults (grey hint text explains why); labels persist in this browser's localStorage and export/import as CSV.
